问题发现 Agent · 底线识别

自研「信息流内容底线治理标准」，按 MECE 原则划分六大类，作为大模型的学习依据；大模型基于标准输出是否违规、违规类型、详情与严重程度，命中即进入 Loop 流程。

六大类：违法与重大安全· 公序良俗与价值观· 引人不适与色情低俗· 内容质量与信息有效性· 旅行相关性· 营销导流与交易合规

🔍
问题发现 Agent
  • 高曝光内容自动巡检，识别低质内容
  • 标签状态前置判断：已有标签 / 库有未打标 / 无标签
  • 按底线标准类型输出 标签 + weighttype 标识（保留原标签字段）
  • weight 与三级标签 1:N 映射：一个 weight 可对应多个存量标签
  • 双大模型交叉验证，聚类定级、影响面排序
输出 → 标签 + weighttype + 标签状态 + 问题类型
→
2
🔗
相似召回 Agent
  • 库有未打标 / 无标签时触发
  • 向量接口召回语义相似内容集
  • 大模型自动化调阈值：多档位分段抽检，取误伤相对较小的阈值回捞
  • 无法全量测准确率（召回量过大），阈值必有误伤 → 需人工确认
  • 达标后打上 weighttype，与标签做映射
输出 → 召回内容集 + weighttype + 推荐阈值（待人工确认）
👤 人工确认阈值
→
3
✅
策略校验 Agent
  • 承接问题发现 / 相似召回分流后的 case
  • 输入：标签 + weighttype + 标签状态 + 召回内容集
  • 通过 weighttype → 查 tag 映射 → 复用对应标签的线上策略
  • 有 tag 仍曝光 → 修配置 / 调参；无现成策略 → 新建策略方案
  • 生成策略方案（治理手段 + 参数 + 实验设计）
输出 → 处置结论 + 策略方案
👤 人工确认治理方案
→
4
⚙️
策略配置 Agent
  • 策略方案 → 策略平台配置生成与落地
  • 上线前自检：推镜像环境 + 功能验证
  • 校验配置无缺陷、策略基本生效
  • 实验分组：调用实验接口建实验、定起始流量
输出 → 策略配置编号 + 实验编号
👤 人工确认进入实验
→
5
🚀
上线发布 Agent
  • 实验观察期 ≥3 天，实验版定向抽验
  • 指标监控：badcase占比
  • 达标 → 按扩量计划自动推全
  • 不达标 → 分型路由（调参 / 回滚 / 人工 / 延长观察）
  • 记录case状态：成功 / 失败 / 人工干预
输出 → 推全或回滚 + badcase处理

📈 最终效果

  • 低质内容发现更及时
  • 治理链路自动化
  • 策略上线更安全（镜像先验）
  • 实验推全更高效
  • case全生命周期可追踪

📚 负反馈学习

  • case + loop双维度记录
  • 精准定位失败原因
  • 反哺检测模型与召回模型
  • 可追溯历史环节与决策
  • 卡点量级分布驱动优化模型
关键顺序：问题发现 Agent → 相似召回 Agent（无标签路径）→ 策略校验 Agent 出方案 → 策略配置 Agent（镜像验证 → 实验分组）→ 上线发布 Agent（推全/回滚）
人工卡点：阈值确认 · 策略方案审核 · 进实验确认 · 边界案例决策  |  镜像不过不进实验
